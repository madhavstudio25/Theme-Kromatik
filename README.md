# Kromatik — Creative Agency & Digital Innovation Studio HTML Template

**Kromatik** is an award-winning editorial and interactive HTML template designed for forward-thinking creative agencies, design studios, digital ateliers, and technology innovators.

Built on pure HTML5, modern CSS3 with custom properties, and vanilla JavaScript powered by GSAP 3, ScrollTrigger, and Lenis smooth momentum scrolling.

## Package Contents

- `Template/`: The complete, production-ready website template with offline vendor libraries and WebP media suite.
- `Documentation/`: In-depth buyer documentation covering installation, tokens, sound design, and custom components.
- `Licenses/`: Detailed credits and license information for all fonts, vendor scripts, and photography.

## Quick Start

1. Open `Template/index.html` directly in any modern web browser or deploy the contents of `Template/` to your web server.
2. Read `Documentation/index.html` for complete setup instructions and customization guides.

## Highlights

- **Kinetic Typography:** Magnetic headline text with interactive cursor dynamics.
- **Precision Custom Cursor:** Multi-state fluid cursor tracking with contextual hover states.
- **Ambient Sound Design:** Web Audio API synthesizer with responsive click/ambient sound and header mute toggle.
- **Initiative Scope Planner:** Client estimator widget with live budget calculations and scope tiers.
- **High-Performance Architecture:** Converted WebP photography (80% file size reduction), offline vendor libraries, and 100% semantic code.

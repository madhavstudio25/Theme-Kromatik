Kromatik Digital Atelier

A premier, award-winning HTML template crafted for creative agencies, design studios, digital ateliers and technology innovators.

Installation & Quick Start

Kromatik is built with pure, modern HTML5, CSS3 and Vanilla JavaScript. It requires no complicated node build steps, package managers or database connections to run.

Offline Ready: All vendor JavaScript libraries (GSAP 3, ScrollTrigger, Lenis) are bundled locally in Template/assets/js/vendor/. The site will function directly off your local disk or any web server without external CDN dependencies.

Deploying to a Server

  1. Extract the submission zip package.
  2. Locate the Template/ directory.
  3. Upload the contents of Template/ to your web host (Apache, Nginx, Vercel, Netlify, Cloudflare Pages, or cPanel) via FTP or git.
  4. Point your browser to your domain or open index.html directly in Chrome, Firefox, Safari or Edge.

Design Tokens & Customization

All colors, font families and spacing variables are declared as CSS custom properties in Template/assets/css/style.css inside the :root selector. You can re-skin the entire template simply by modifying these values:

:root {
  /* Core Atelier Palette */
  --forest-dark: #142016;       /* Primary dark forest background */
  --forest-surface: #1B2B1E;    /* Elevated card surface */
  --forest-surface-2: #233627;  /* Hover / active card surface */
  --yellow-accent: #E2F804;     /* High-voltage neon acid yellow */
  --yellow-ink: #111A13;        /* High-contrast dark ink on yellow */

  /* Light Editorial Cream Theme */
  --cream-bg: #F6F4ED;          /* Light cream editorial canvas */
  --cream-ink: #141714;         /* Deep editorial text color */
  --cream-card: #FFFFFF;        /* White card surface */
  --cream-muted: #6B7268;       /* Subtle secondary muted text */
}

Typography & Google Fonts

Kromatik uses two open-source typefaces loaded from Google Fonts:

  • Space Grotesk: Display headings, kickers, numbers and buttons (weights: 500, 600, 700, 800).
  • Inter: Body paragraphs, metadata, navigation and documentation (weights: 400, 500, 600, 700).

To change fonts, swap the <link> in <head> and update --font-display and --font-body in style.css.

Sound Design Engine

Kromatik features an ambient Web Audio API synthesizer that responds to interactions. Audio is enabled by default with a convenient mute toggle in the navigation bar and mobile drawer.

Configuring Default Sound: In assets/js/main.js, locate Section 12 (Ambient Sound Engine). You can adjust frequencies, synth volume, or set the default sound state.

Replacing Images & Media

Images are stored in Template/assets/images/. The template uses a modern <picture> strategy serving ultra-lightweight .webp files with standard .jpg fallbacks:

<picture>
  <source srcset="assets/images/team-hero.webp" type="image/webp">
  <img src="assets/images/team-hero.jpg" alt="Creative Team" width="1600" height="900" loading="lazy" decoding="async">
</picture>

To swap an image, replace both the .jpg and .webp files under the same filename to retain optimal loading performance across all browsers.

Interactive Widgets

Kromatik includes several bespoke interactive modules:

  • Interactive Dot Field Canvas: Dynamic cursor-interactive particle matrix in the hero header.
  • Initiative Scope Planner: Client project estimator with interactive tier pills and live budget calculations.
  • Kinetic Custom Cursor: Dual-ring cursor tracker that morphs when hovering cards, video badges and action buttons.
  • Accolades Thumbnail Hover: Floating project preview follower that tracks cursor coordinates over award titles.
